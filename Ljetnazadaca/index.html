Izračun površine pravokutnika

  • 1. Izračun površine pravokutnika:✅

    1. Izračun površine pravokutnika:✅ Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese duljinu i širinu pravokutnika, a zatim izračunava i ispisuje površinu pravokutnika.

    Povrsina pravokutnika
  • 2. Provjera broja -, +. 0 ✅

    2. Provjera je li broj pozitivan, negativan ili nula:✅ Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese broj i ispisuje je li broj pozitivan, negativan ili nula.

    Provjera broja
  • 3. Zbroj elemenata niza ✅

    3. Zbroj elemenata niza: Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji deklarira niz, traži od korisnika da unese vrijednosti u niz, a zatim izračunava i ispisuje zbroj svih elemenata niza koji su brojčanog tipa.

    Zbroj elemenata niza
  • 4. Prosjek ocjena✅

    4. Prosjek ocjena: Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese broj ocjena, a zatim i same ocjene. Program treba izračunati i ispisati prosjek ocjena.

    Prosjek ocjena
  • 5. Fibonaci niz:✅

    5.Fibonaci niz Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese broj n, a zatim ispisuje prvih n brojeva Fibonaccijevog niza (0, 1, 1, 2, 3, 5, 8...)..

    Fibonaci niz
  • 6. Preokret stringa ✅

    6. Preokret stringa: Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese string, a zatim ispisuje taj string naopako (npr. "zdravo" postaje "ovardz").

    Preokret stringa
  • 7. Brojanje samoglasnika ✅

    7. Brojanje samoglasnika: Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese string, a zatim prebrojava i ispisuje koliko samoglasnika ima u tom stringu.

    Brojanje samoglasnika
  • 9. Sortiranje niza ❌

    9. Sortiranje niza: Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji deklarira niz, traži od korisnika da unese vrijednosti u niz, a zatim sortira niz uzlazno i ispisuje sortirani niz.

    sortiranje niza
  • 10. Kalkulator ✅

    10. Kalkulator: Kreiraj HTML, lijepo ga stiliziraj s CSS te u JS napiši program koji od korisnika traži da unese dva broja i operaciju (+, -, *, /), a zatim izračunava i ispisuje rezultat. Koristi switch za odabir operacije.

    Kalkulator
